# Uploading Items

## 📸 How to Upload Items for Scanning

### Upload Methods

#### 📱 Mobile App
1. **Take Photo** (Recommended)
   - Tap "Take Photo" button
   - Allow camera permissions
   - Frame item and snap
   - Photo uploads automatically

2. **Choose from Gallery**
   - Tap "Upload Photo" button
   - Allow photo access
   - Select item image
   - Tap to confirm

#### 💻 Web Browser
1. **Drag & Drop** (Easiest)
   - Drag image file from computer
   - Drop on upload area
   - See preview before analyzing

2. **Click to Browse**
   - Click upload area
   - Browse for image file
   - Select and open

3. **Paste from Clipboard**
   - Copy image (Cmd/Ctrl+C)
   - Click upload area
   - Paste (Cmd/Ctrl+V)

4. **Take Photo with Webcam**
   - Click "Take Photo"
   - Allow camera access
   - Snap photo

### Image Requirements

#### ✅ Accepted Formats
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif) - static only
- WebP (.webp)
- HEIC (.heic) - iPhone photos
- HEIF (.heif) - iPhone photos

#### 📏 Size Limits
- **Maximum**: 10MB per image
- **Recommended**: 2-5MB for best speed
- **Minimum**: No minimum, but very small images may not analyze well

#### 📸 Photo Tips for Best Results
1. **Good lighting** - Natural light preferred
2. **Clear focus** - Avoid blurry photos
3. **Full item visible** - Include all details
4. **Plain background** - Helps with recognition
5. **Multiple angles** - Can upload again for different views

### Common Upload Issues

#### "File Too Large" Error
**Problem**: Image exceeds 10MB limit

**Solutions**:
- Use phone's camera directly (auto-optimizes)
- Reduce image quality in camera settings
- Use photo editing app to resize
- Screenshot the photo (reduces size)

#### "Only Image Files Allowed" Error
**Problem**: Trying to upload non-image file

**Solutions**:
- Check file extension
- Make sure it's an image, not PDF or document
- Try different image format

#### Upload Stuck or Frozen
**Problem**: Progress bar not moving

**Solutions**:
1. Check internet connection
2. Refresh page/app
3. Try smaller image
4. Clear app cache
5. Try different upload method

#### Camera Not Working
**Mobile Issues**:
- Go to Settings → Flippi → Allow Camera
- Close other camera apps
- Restart phone if needed

**Web Issues**:
- Click lock icon in address bar
- Allow camera permissions
- Try different browser
- Check if camera works in other apps

#### Gallery Access Denied
**Fix on iOS**:
1. Settings → Flippi
2. Photos → "All Photos"

**Fix on Android**:
1. Settings → Apps → Flippi
2. Permissions → Storage → Allow

### Platform-Specific Tips

#### iPhone/iOS
- HEIC photos work directly
- Use "Most Compatible" setting for smaller files
- AirDrop to yourself to convert formats

#### Android
- Default camera settings usually work
- Google Photos can compress if needed
- Share via Flippi from gallery

#### Web/Desktop
- Drag & drop is fastest
- Paste works from any app
- Screenshots work well for quick scans

### After Upload

#### What Happens Next
1. Image uploads in background
2. AI analyzes the item
3. Results appear in 2-5 seconds
4. Get price estimates and recommendations

#### Scan Another Item
After results show:
- Tap "Scan Another Item"
- Previous results are saved
- Start fresh upload

#### Upload Not Working?
Try these in order:
1. Different upload method
2. Different image
3. Refresh app/page
4. Sign out and back in
5. Contact support

### Privacy & Security

- Images processed in real-time
- Not stored on servers
- Encrypted upload connection
- Only you see your scans
